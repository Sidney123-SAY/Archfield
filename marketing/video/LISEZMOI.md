# Vidéo de présentation

`archfield-presentation.mp4` : 56 secondes, 1920 × 1080, 30 images par seconde, sans son, prête pour LinkedIn, YouTube, une présentation ou WhatsApp.

Les 9 scènes :
1. le nom ;
2. le problème (construire de loin, par messages) ;
3. la promesse, avec le plan de façade qui se construit ;
4. le rapport du jour du chef de chantier ;
5. les photos vérifiées ;
6. l'argent ;
7. le tableau du dirigeant ;
8. les trois espaces ;
9. la fin, avec « Deux mois offerts ».

Les `image-*.jpg` sont une image fixe par scène, pour les publications.

**Musique** : ajoutez-en une libre de droits dans CapCut ou YouTube Studio (bibliothèque audio). La vidéo est rythmée pour un morceau calme, d'environ 90 à 110 battements par minute.

**Modifier les textes** : éditez `tools/video/video.html`, puis lancez `npm run video` (il faut ffmpeg). La nouvelle vidéo arrive dans `video/out/`.
